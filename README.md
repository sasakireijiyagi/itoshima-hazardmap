# さくさく動く糸島ハザードマップ

福岡県糸島市のハザードマップを，**複数の災害を重ねて**見られる軽量ビューアです。

[いとしま一目瞭然](https://itoshima-watch.sasakireijiyagi.com/)シリーズの1本です。

**公開先 → https://itoshima-watch.sasakireijiyagi.com/hazard/**

> これは糸島市の公式サイトではありません。個人が公開データを使って作った非公式のビューアです。
> 避難の判断は，糸島市の防災情報と気象庁の気象情報に従ってください。

## できること

- **10種類のハザードを重ねて表示** — 洪水（想定最大規模／計画規模），浸水継続時間，家屋倒壊等氾濫想定区域（氾濫流／河岸侵食），津波，高潮，急傾斜地の崩壊，土石流，地すべり。レイヤーごとに濃さを調整できます。
- **地点診断** — 地図をタップすると，表示中かどうかに関係なく**10種類すべてを同時に判定**し，浸水深や区域区分を一覧で出します。標高と住所も表示します。
- **災害に対応した避難場所** — その地点で想定される災害ごとに，指定されている指定緊急避難場所を近い順に出します。複数の災害が重なる地点では，どの災害に対応する場所かを札で示します。すべてに対応するとは限りません。
- 住所・地名検索，現在地，背景地図の切り替え（淡色／標準／航空写真），陰影起伏の重ね合わせ。
- 地図の位置と表示中の層はURLに保存されるので，そのまま人に送れます。自宅などを表示したURLを送ると，その場所が伝わります。

内水（雨水出水）は，全国配信データに市域のデータがないため，レイヤーには含めていません。ため池の決壊，地震，想定の作られていない中小河川も判定の対象外です。「該当なし」は公表された想定区域の外という意味で，安全という意味ではありません。

## 技術的なこと

ビルド不要の単一HTMLファイルです。Leaflet 1.9.4 を同梱しています。外部へ通信するのは国土地理院のサーバだけで，地図タイルのほか，タップ地点の住所・標高の問い合わせと住所検索があります。表示範囲，座標，検索語は利用者の端末から直接送られ，先方のアクセス記録に残ることがあります。このサイトの運営者には届きません。

地点診断は，配信されているタイル画像の該当ピクセルの色を読み取り，国土交通省の凡例と突き合わせて判定しています。区域の境界付近では実際の指定と差が出ることがあるため，正式な確認は原典図でお願いします。

## 出典

- ハザードマップ各層 — 出典：「[ハザードマップポータルサイト](https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html)」。「ハザードマップポータルサイト」を加工して作成（地図の重ね合わせと，タイルの色から地点の区分を文章にする処理）。作成元は，洪水・浸水継続時間・家屋倒壊が国土交通省各地方整備局等と都道府県，津波・高潮が都道府県。土砂災害は「国土数値情報（令和７年度土砂災害警戒区域）」（国土交通省）をもとに国土地理院が加工したもの。
- 背景地図・陰影起伏 — [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)／標高 — 国土地理院／住所検索 — 地理院地図（協力：東大CSIS）
- 指定緊急避難場所 — 出典：国土地理院ウェブサイト（https://www.gsi.go.jp/bousaichiri/hinanbasho.html）。「指定緊急避難場所データ」（国土地理院）を AIGID が加工して作成した[データ](https://www.geospatial.jp/ckan/dataset/hinanbasho)を，ヤギ製作所が加工して作成。2026年10月に国土地理院の配信データと照合し，1か所を追加。最新でない場合や未掲載の場合があるので，最新の情報は糸島市で確認してください。
